# UI fonts
- LilitaOne-Regular.ttf: existing static Lilita One, weight 400; titles/buttons/numbers/names.
- Fredoka-SemiBold.ttf: static instance of official Google Fonts Fredoka variable, wght=600, wdth=100; descriptions/help/small text. Full printable English ASCII verified.
- Sources: https://fonts.google.com/specimen/Lilita+One and https://github.com/google/fonts/tree/main/ofl/fredoka
- Keep both OFL license files. Fredoka instantiated with fontTools.varLib.instancer; no glyph outlines edited.
- UI wiring is reserved for UI-005; adding fonts does not change existing UI.
