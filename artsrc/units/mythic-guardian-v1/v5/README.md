# Mythic v5 — mana aura and other race concepts

Preview only, no Unity integration.

Guardian: after 1.2-second activation, returns to walk/normal attack while aura follows caster. Starts at demo MP100; drain 15/second continuous, no mana gains from attacking, receiving hits or any other source while active. Aura ends at MP0 after 6.667 seconds; walk/normal attack continue. Demo never automatically refills MP. Clicking Skill starts a fresh test. Aura damage is .2 ATK per second per in-range target, self-heal .5 actual aura damage capped to max HP. Normal attacks displayed separately, not counted toward aura healing. Target dummies have 1000 HP so they survive several demonstration hits.

Other-mythics.png: built-in imagegen concept sheet based on the existing four Legendary race sprites. Prompt direction: 2x2 simple faceless chibi flat fantasy, new silhouettes for Elf oracle with crescent staff, Undead warden with scythe, white thunder bear with hammer, ivory/charcoal golem with cyan core. These are visual candidates only, no assigned skill or animation set yet.
