# Home walking loop v1

Preview only. Three layers generated with built-in image_gen; not imported into Unity. Demo uses existing 15-frame Walk sprites, no regenerated characters. Mirrored alternating tile instances hide non-identical generated edge profiles; final production loop should be reviewed at seam boundaries. UI stays fixed. No game files changed.

## sky

Use case: stylized-concept. Asset type: production 2D horizontally scrolling background layer for a slow walking home-screen scene in SpinSquad Again. Reference is actual game art: simple clean black outlines, flat lime green rounded trees, angular blue mountains, cyan sky. Match this modest art exactly, no ornate concept art, no characters, UI, letters, props, castles, roads receding into distance or perspective vanishing point. Wide landscape 3:1 image. Horizontally tileable left-to-right loop with carefully matching left/right edge heights, shapes and colors. Camera side-on shallow 2D scene, level horizontal ground, no vertical camera movement. Sky and distant mountains ONLY. Opaque cyan sky with two simple small flat white clouds near top, a horizontal chain of angular blue mountains in bottom 40 percent. Same blue tones as reference. Mountain profile and background colors connect seamlessly across left/right. No trees or ground. Large clean sky negative space for fixed UI.
