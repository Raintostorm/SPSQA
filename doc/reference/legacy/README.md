# Tham khảo lịch sử — không dùng làm luật hiện hành
Bảy ghi chú kỹ thuật/design cũ được giữ để tra cứu lỗi, dữ liệu và lý do quyết định. Chúng có số liệu, đường dẫn, Spine/part pipeline hoặc công thức đã bị thay thế. Mặc định không đọc cả thư mục.

Dùng STATUS / GAME_RULES / BUFFS ở `doc/` cho hành vi hiện hành. Khi cần một lỗi cụ thể mới đọc `11-LOI-DA-GAP.md`; pipeline frame hiện hành nằm trong runtime manifest và README art tương ứng.

Đã bỏ các hướng dẫn bắt đầu lại repo, copy từ project cũ, milestone tạo game từ đầu, ranh giới dùng AI, dọn Git cũ và kế hoạch chuyển portrait đã xong. Chúng không còn là kế hoạch của SpinsquadAgain.
